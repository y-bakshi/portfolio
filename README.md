# Yash Bakshi Portfolio

A mobile-first technical portfolio presented as a mid-century engineering journal. The site will showcase AI application engineering, backend systems, and selected software projects through editorial case studies and an interactive portfolio guide.

## Repository Layout

```text
apps/
└── web/    Astro frontend with Vue interactive islands
```

The future FastAPI backend will live in `apps/api/`.

## Development

```sh
cd apps/web
npm ci
npm run dev
```

Before submitting changes, run:

```sh
npm run check
npm run build
```

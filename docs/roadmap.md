# Roadmap

The GitHub repository is public. Build and validate the website privately until the complete integrated experience is ready. Desktop and mobile functionality have equal priority in every phase.

## Completed: Scaffold

- Astro, TypeScript, and Vue integration in `apps/web/`.
- Placeholder homepage; `check` and production `build` scripts.
- Initial Git commit and GitHub remote.
- Agent context/private briefs excluded from Git.
- Technical documentation created; planned services remain unimplemented.

## Phase 1: Editorial Foundation

Define design tokens, licensed fonts, layout primitives, content schemas, routes, masthead, hero, and About. Exit: responsive structure works across desktop/touch layouts, keyboard access works, and content builds from validated records.

## Phase 2: Publication and Evidence

Build featured exhibits, archive filters, case-study template, lab report, professional record, résumé, and contact desk. Include the broader project catalog with stronger AI/SDE emphasis. Exit: published claims are verified, diagrams/captions are accurate, and all destinations work.

## Phase 3: Artwork

Obtain an approved real portrait and create an engraved/halftone derivative. Produce consistent monochrome/red project exhibits, diagrams, paper treatments, icons, and social preview. Exit: licenses and provenance recorded, assets optimized, text/contrast preserved.

## Phase 4: Text Guide

Create FastAPI backend, versioned evidence artifact, Vue guide, Bloub states, grounded answers, citations, navigation dispatcher, sessions, quota transactions, and provider mocks. Exit: invalid claims/actions are rejected, guidance is controllable, and concurrent budget admission is tested.

## Phase 5: Voice and Privacy

Select model/speech providers after cost/latency tests. Add optional microphone and audio, App Check enforcement, feedback, redaction, retention cleanup, quotas, and kill switches. Exit: typed fallback works; live-provider usage is bounded and privacy statements match actual behavior.

## Phase 6: Release Hardening

Configure GCP resources, reproducible deployment, CI/CD gates, security headers, rollback, observability, and spend controls. Run accessibility, real-device, performance, failure, grounding, and cost tests. Exit: all critical cases pass with evidence, owner approves launch, domain and scheduling are configured.

## Decisions Still Needed

Exact typography, final domain, calendar service, model/voice providers, measured quotas, featured order, initial complete case-study coverage, and whether the Bloub design remains at release. Do not block static-site work on provider selection.
